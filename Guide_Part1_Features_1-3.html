How it works: Shows consecutive-day streak via context processor (runs on every page load). Active streak shows fire emoji. Frozen streak shows snowflake. No streak prompts user to start.

Feature 3: Milestone Badges

How it works: 4 badge tiers (3, 7, 14, 30 days). Backend compares streak against thresholds, builds earned badges with achievement dates. Freeze token earned at every 7-day milestone.
